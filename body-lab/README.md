# BODY LAB v2 — 독립 체형 조절 실험

별도 브랜치 `experiment/part-based-body-v2` 안에 설치하는 독립적인 체형 조절 프로토타입이다. 원래 게임의 `index.html`, UI, 4개 방, 헤어·메이크업, 의상은 건드리지 않는다.

## 실행

`body-lab/index.html`을 브라우저로 열면 된다. 웹서버·외부 라이브러리·계정이 필요 없다.

## 파일 구조

- `index.html`: 단독 체형 실험 UI
- `style.css`: PC / 모바일 반응형 레이아웃
- `geometry.js`: 파츠 윤곽을 계산하는 독립 벡터 체형 엔진
- `app.js`: 프리셋, 조절 슬라이더, 파츠 합성, 투명 SVG/PNG와 JSON 출력
- `assets/parts/*.svg`: 16개 독립 투명 신체 파츠, 모두 `252×730` 좌표 원점에 맞춰 생성

## 구조

기존 코드는 `252×730` PNG들을 합친 뒤 WebGL/Canvas로 변형했다. 이 코드는 원본 PNG의 픽셀을 늘리지 않고 각 부위의 외곽선, 관절 위치, 베지어 제어점을 직접 바꾼다. 머리, 목, 상체, 골반, 좌우 위팔·아래팔·손·허벅지·종아리·발을 분리한다.

개별 이미지 파일은 기준 체형 100% 상태의 투명 SVG 스프라이트이다. 실시간 화면은 **같은 곡선 계산 함수**를 사용해 각 파츠를 다시 그린다. 따라서 파츠 이미지 파일을 무리하게 늘리지 않는다.

## 테스트 조절

11개의 슬라이더(머리, 목, 어깨, 가슴, 허리, 골반, 상·하체 비율, 팔 굵기, 팔 길이, 허벅지, 종아리), 4개 프리셋, 관절점 가이드, 투명 바탕 확인, JSON·SVG·PNG 다운로드를 제공한다.

## 제한과 다음 작업

- 이번 파일은 **절차적으로 그린 벡터 아트 시안**이다. AI 이미지 생성 모델의 결과물로 표시하지 않는다. 최종 일러스트에 사용할 경우 기존 게임의 선화와 얼굴 표현에 맞춘 재작업이 필요하다.
- **기존 의상과 통합하지 않았다.** 새 체형에 맞춰 입혀보려면 신체 관절/실루엣 기준에 따라 의상 파츠를 재설계해야 한다.
- `main` 브랜치에는 아무 변경도 하지 않는다.
