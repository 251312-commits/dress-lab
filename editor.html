의상 정보 생성기

의상 파일을 고르고 이름·카테고리·캔버스 규격·앞뒤 순서를 지정하면 item.json을 내려받는다. PNG와 JSON을 같은 GitHub 의상 폴더에 올리면 배포 시 자동 등록된다.

① 의상 정보

격자 보기·다운로드인형과 동일한 252 × 730 원점

② 앞/뒤 레이어 PNG 선택

여러 장 선택 가능. 각 이미지의 투명한 캔버스 크기는 선택한 규격과 정확히 같아야 한다. 선택한 파일은 서버에 전송하지 않는다.

PNG 파일을 선택하면 레이어가 나타난다.

③ 설정 파일 다운로드

먼저 GitHub에 clothes/고유ID/ 폴더를 만들고, 선택한 PNG와 내려받은 item.json을 함께 넣는다. 저장소를 수정하지 않고 이 페이지에서 파일만 생성한다.
